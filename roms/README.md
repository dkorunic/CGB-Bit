# Bundled game

`tobudx.gb` is **Tobu Tobu Girl Deluxe** by Tangram Games (Simon Larsen), an arcade platformer for
the Game Boy, Game Boy Color and Super Game Boy, the game CGB-Bit flashes by default. On the Bit it
runs in Game Boy Color mode.
