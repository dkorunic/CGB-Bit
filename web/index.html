CGB-Bit: Game Boy Color on the CircuitMess Bit

Game Boy and Game Boy Color games on the Bit, flashed straight from your browser, with Tobu Tobu Girl Deluxe to play out of the box. Version ….

  1. Use desktop Chrome, Edge or Opera (they have Web Serial; Firefox and Safari don't).
  2. Connect the Bit with a USB-C data cable and switch it on.
  3. Press Connect, pick the Bit's serial port, then Install. Leave Erase device unticked to keep your saves.
  4. When it's done, switch the Bit off and on.
Your browser can't flash devices. Open this page in desktop Chrome, Edge or Opera. Flashing needs a secure (https) page.

Your own game

Pick a Game Boy or Game Boy Color game (.gb, .gbc, up to 4 MB) on your computer: homebrew (the Homebrew Hub lists many free ones) or a dump of a cartridge you own. It's checked here first and goes straight from this page to the Bit; it isn't uploaded anywhere.

"Replace the game only" needs CGB-Bit on the Bit already and keeps it; "Install CGB-Bit with this game" also (re)installs CGB-Bit itself. With "Replace the game only", don't tick "Erase device": that erases CGB-Bit too and leaves the Bit without firmware (fix it with either install button).

This replaces the Bit's stock firmware (or the game already on it).

Installing keeps the save unless you tick "Erase device". A game only ever loads its own save. The Bit has room for one game's save: once a different game has saved twice, the previous game's save is gone.

Bundled game: Tobu Tobu Girl Deluxe by Tangram Games (code MIT, assets CC BY 4.0).
